## Slide 5: How It Works

```
┌───────────────────────────────────────────────────────┐
│                  HOW IT WORKS                         │
│              (35-45 Day Life Cycle)                   │
├───────────────────────────────────────────────────────┤
│                                                       │
│    ┌─────────┐                                        │
│    │ ADULT   │ 5-8 days                              │
│    │ FLIES   │ Lay 500-900 eggs, don't eat           │
│    └────┬────┘                                        │
│         │ Eggs                                        │
│         ▼                                               │
│    ┌─────────┐                                        │
│    │ LARVAE  │ 14-18 days ← HARVEST HERE              │
│    │         │ Eat organic waste, grow 10,000x       │
│    └────┬────┘ High protein/fat                      │
│         │                                             │
│         ▼                                               │
│    ┌─────────┐                                        │
│    │ PREPUPAE│ 5-7 days                               │
│    │         │ Stop eating, seek dry area            │
│    └────┬────┘ (can also harvest)                    │
│         │                                             │
│         ▼                                               │
│    ┌─────────┐                                        │
│    │ PUPAE   │ 10-14 days                             │
│    │         │ Transformation                        │
│    └────┬────┘                                        │
│         │                                             │
│         └────────────→ Back to Adult Flies            │
│                                                       │
│  FEEDSTOCK: Fruit/veg waste, brewery waste, ag waste │
│  OUTPUT: 5-20 kg larvae per m² per month             │
│                                                       │
└───────────────────────────────────────────────────────┘
```

**Speaker Notes:**
- Simple biological process
- Adult flies lay eggs, don't eat or bite
- Larvae consume waste and grow rapidly
- Harvest at 14-18 days (peak nutrition)
- Feed live, dried, or fresh to chickens
- Frass (waste) becomes organic fertilizer
