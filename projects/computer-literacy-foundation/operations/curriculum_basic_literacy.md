# CURRICULUM: Basic Computer Literacy
## Level 1 - Foundation Course

**Duration:** 4-6 weeks (12-18 sessions, 2-3 hours per session)  
**Target Audience:** Complete beginners (no prior computer experience)  
**Class Size:** 10-15 students (1 computer per 2 students max)  
**Prerequisites:** None

---

## COURSE OVERVIEW

### Learning Objectives

By the end of this course, students will be able to:

1. Identify and use basic computer hardware components
2. Navigate the Windows operating system confidently
3. Create, save, and organize files and folders
4. Use a keyboard and mouse effectively
5. Connect to the internet and browse websites
6. Create and use an email account
7. Practice basic digital safety and security
8. Use common software applications (calculator, notepad, etc.)

### Assessment

- **Attendance:** Minimum 80% required
- **Practical Tests:** 4 hands-on assessments
- **Final Project:** Complete a simple task using learned skills
- **Certificate:** Awarded upon successful completion

## WEEKLY BREAKDOWN

### Week 1: Introduction to Computers

#### Session 1.1: What is a Computer? (2 hours)

**Topics:**
- What is a computer? (definition and examples)
- Types of computers (desktop, laptop, tablet, smartphone)
- Uses of computers in daily life
- Basic computer components (monitor, CPU, keyboard, mouse, speakers)
- Turning computer on and off properly

**Practical Activities:**
- Identify computer parts on actual machines
- Practice proper startup and shutdown procedures
- Explore the computer lab

**Materials Needed:**
- Computers (1 per 2 students)
- Printed diagrams of computer parts
- Whiteboard/flipchart

**Key Vocabulary:**
- Computer, Desktop, Laptop, Monitor, CPU, Keyboard, Mouse, Power button

**Homework:**
- Draw and label a computer setup
- List 5 ways computers are used in your community

---

#### Session 1.2: The Keyboard (2 hours)

**Topics:**
- Keyboard layout overview
- Letter keys, number keys, special keys
- Function keys (F1-F12)
- Special keys: Enter, Space, Backspace, Delete, Shift, Caps Lock
- Proper finger positioning (basic)

**Practical Activities:**
- Identify different key types
- Practice typing letters and numbers
- Use Shift for capital letters
- Use Enter, Space, Backspace correctly

**Typing Practice:**
- Home row introduction (A S D F - J K L ;)
- Simple typing exercises
- Typing games (if available)

**Homework:**
- Practice typing your name 20 times
- Type the alphabet 5 times

---

#### Session 1.3: The Mouse (2 hours)

**Topics:**
- Parts of the mouse (left button, right button, scroll wheel)
- Mouse gestures: Click, Double-click, Right-click, Drag and Drop
- Mouse pointer shapes and meanings
- Proper mouse grip and movement

**Practical Activities:**
- Practice clicking on icons
- Double-click to open programs
- Right-click to see context menus
- Drag and drop files
- Use scroll wheel to navigate

**Games/Exercises:**
- Solitaire (for click practice)
- Simple mouse skill games
- Drawing with Paint program

**Homework:**
- Practice mouse skills at home (if accessible)
- Write down 3 things you learned about using a mouse

---

### Week 2: Operating System Basics

#### Session 2.1: Introduction to Windows (2 hours)

**Topics:**
- What is an operating system?
- Windows desktop overview
- Taskbar and Start menu
- Desktop icons
- Windows, minimizing, maximizing, closing

**Practical Activities:**
- Navigate the desktop
- Open programs from Start menu
- Work with multiple windows
- Minimize, maximize, restore, close windows
- Arrange windows on screen

**Key Skills:**
- Finding programs
- Switching between programs
- Organizing desktop workspace

**Homework:**
- Draw the Windows desktop from memory
- List 5 programs you can open from Start menu

---

#### Session 2.2: Files and Folders - Part 1 (2 hours)

**Topics:**
- What are files and folders?
- File types (documents, pictures, music, videos)
- File extensions (.txt, .doc, .jpg, .pdf)
- Creating folders
- Naming files and folders

**Practical Activities:**
- Create a folder with your name
- Create subfolders (Documents, Pictures, etc.)
- Practice naming conventions
- Explore different file types in the system

**Key Skills:**
- Create folders
- Name files appropriately
- Understand file organization

**Homework:**
- Plan a folder structure for your personal files
- Write down 10 file names you might use

---

#### Session 2.3: Files and Folders - Part 2 (2 hours)

**Topics:**
- Saving files
- Opening existing files
- Copying files and folders
- Moving files and folders
- Deleting and restoring from Recycle Bin
- Searching for files

**Practical Activities:**
- Create and save a text document
- Copy files between folders
- Move files using drag and drop
- Delete files and restore from Recycle Bin
- Use Search function to find files

**Key Skills:**
- Save files in correct locations
- Organize files efficiently
- Manage file storage

**Homework:**
- Create a folder structure on paper for your documents
- Practice file management if you have computer access

---

### Week 3: Basic Software Applications

#### Session 3.1: Introduction to Word Processing (2 hours)

**Topics:**
- What is word processing?
- Opening Notepad/WordPad
- Typing text
- Basic formatting (bold, italic, underline)
- Font size and style
- Text alignment

**Practical Activities:**
- Open Notepad/WordPad
- Type a short paragraph about yourself
- Format text (bold, italic, underline)
- Change font size and style
- Align text (left, center, right)
- Save the document

**Project:**
- Create a simple bio document (1 paragraph)
- Include name, age, hometown, interests
- Format with different styles

**Homework:**
- Write a short letter to a friend (on paper)
- Bring to next class to type

---

#### Session 3.2: Working with Documents (2 hours)

**Topics:**
- Opening existing documents
- Editing text (insert, delete, replace)
- Selecting text (word, line, paragraph, all)
- Cut, Copy, Paste
- Undo and Redo
- Spell check (if available)

**Practical Activities:**
- Open previous bio document
- Make edits and corrections
- Practice cut, copy, paste
- Use undo and redo functions
- Check spelling
- Save changes

**Project:**
- Type the letter to friend (from homework)
- Format appropriately
- Save and print (if printer available)

**Homework:**
- Practice typing a simple recipe or instructions

---

#### Session 3.3: Other Useful Programs (2 hours)

**Topics:**
- Calculator (basic and scientific)
- Paint (basic drawing)
- Media Player (playing music/videos)
- Screenshot tool
- System settings (volume, display)

**Practical Activities:**
- Use Calculator for math problems
- Create a simple drawing in Paint
- Play a music file or video
- Take a screenshot
- Adjust volume and display settings

**Key Skills:**
- Use built-in Windows tools
- Basic troubleshooting (volume, display)

**Homework:**
- Use calculator to solve 5 math problems
- Draw something simple in Paint (if accessible)

---

### Week 4: Introduction to the Internet

#### Session 4.1: What is the Internet? (2 hours)

**Topics:**
- What is the internet?
- Uses of the internet (communication, information, entertainment, business)
- Internet connection types (WiFi, mobile data, ethernet)
- Web browsers (Chrome, Firefox, Edge)
- Opening a browser
- Understanding URLs/web addresses

**Practical Activities:**
- Connect to internet (WiFi or ethernet)
- Open different web browsers
- Identify browser parts (address bar, tabs, back/forward buttons)
- Type a URL and navigate to website
- Use back, forward, refresh buttons

**Key Vocabulary:**
- Internet, Website, Browser, URL, Link, Homepage

**Homework:**
- List 5 websites you would like to visit
- Write down 3 ways you could use the internet in your life

---

#### Session 4.2: Web Browsing (2 hours)

**Topics:**
- Using search engines (Google)
- Entering search queries
- Understanding search results
- Clicking on links
- Opening links in new tabs
- Bookmarks/Favorites
- Downloading files (safely)

**Practical Activities:**
- Search for information on Google
- Evaluate search results
- Click on links safely
- Open multiple tabs
- Bookmark useful websites
- Download a simple file (PDF, image)

**Safety Topics:**
- Identifying safe vs. suspicious websites
- Not clicking on pop-ups
- Not downloading unknown files

**Homework:**
- Search for information about your hometown
- Find and bookmark 3 useful websites

---

#### Session 4.3: Online Information & Services (2 hours)

**Topics:**
- Finding government information online
- Checking news websites
- Educational resources (Khan Academy, etc.)
- Job search websites
- Online forms (basic)
- Evaluating information credibility

**Practical Activities:**
- Visit Ghana government website
- Find information on a topic of interest
- Explore a job search website
- Fill out a simple online form
- Compare information from multiple sources

**Key Skills:**
- Find reliable information online
- Use online services
- Critical thinking about online content

**Homework:**
- Find one useful piece of information online
- Bring to class to share

---

### Week 5: Email & Communication

#### Session 5.1: Introduction to Email (2 hours)

**Topics:**
- What is email?
- Email addresses (format and parts)
- Email providers (Gmail, Yahoo, Outlook)
- Creating an email account
- Understanding inbox, sent, drafts, trash

**Practical Activities:**
- Choose an email provider
- Create a personal email account
- Understand email interface
- Identify inbox, sent items, drafts
- Log in and log out properly

**Security Topics:**
- Creating strong passwords
- Not sharing passwords
- Recognizing email scams

**Homework:**
- Write down your email address and password (keep safe!)
- Think of 3 people you would like to email

---

#### Session 5.2: Sending and Receiving Email (2 hours)

**Topics:**
- Composing a new email
- To, CC, BCC fields
- Writing subject lines
- Writing email body
- Attaching files
- Sending emails
- Reading received emails
- Replying and forwarding

**Practical Activities:**
- Compose and send an email to instructor
- Send email to classmate (if emails exchanged)
- Attach a document to email
- Read received emails
- Reply to an email
- Forward an email

**Email Etiquette:**
- Professional email writing
- Proper greetings and closings
- Checking spelling before sending
- Appropriate subject lines

**Homework:**
- Send an email to a friend or family member
- Reply to instructor's email

---

#### Session 5.3: Email Management (2 hours)

**Topics:**
- Organizing emails (folders/labels)
- Deleting unwanted emails
- Searching for emails
- Blocking spam
- Logging out safely
- Email on mobile devices (overview)

**Practical Activities:**
- Create email folders/labels
- Organize inbox
- Delete spam/unwanted emails
- Search for specific emails
- Mark emails as important
- Practice safe logout

**Security Review:**
- Recognizing phishing emails
- Not clicking suspicious links
- Not sharing personal information

**Homework:**
- Organize your email inbox
- Send a thank you email to someone

---

### Week 6: Digital Safety & Final Assessment

#### Session 6.1: Digital Safety and Security (2 hours)

**Topics:**
- Creating strong passwords
- Protecting personal information
- Recognizing scams and fraud
- Safe online shopping (overview)
- Social media safety (overview)
- Computer viruses and antivirus
- Backing up important files

**Practical Activities:**
- Evaluate password strength
- Review privacy settings (if social media accounts)
- Identify scam emails (examples)
- Discuss safe online practices
- Learn about antivirus software

**Discussion:**
- Share experiences with technology
- Discuss concerns and questions
- Best practices for staying safe online

**Homework:**
- Change any weak passwords
- Review privacy settings on any accounts

---

#### Session 6.2: Review and Practice (2 hours)

**Activities:**
- Review all topics covered
- Open Q&A session
- Practice weak areas
- Final project work time
- Peer help and collaboration

**Final Project:**
Students complete a comprehensive task:
1. Create a folder with their name
2. Write a document about themselves (using WordPad)
3. Save it in their folder
4. Send it as email attachment to instructor
5. Search online for information about a topic and bookmark it

**Instructor Assessment:**
- Observe students completing tasks
- Provide help as needed
- Note areas of strength and weakness

---

#### Session 6.3: Final Assessment & Graduation (2 hours)

**Final Practical Test (1 hour):**
Students complete assigned tasks independently:
1. Turn on computer and log in
2. Create a folder with specific name
3. Open WordPad and type a short paragraph
4. Format text (bold, italic, change size)
5. Save document in created folder
6. Open browser and search for specific information
7. Create email and send to instructor
8. Shut down computer properly

**Certificate Ceremony (1 hour):**
- Review course highlights
- Distribute certificates
- Student testimonials (voluntary)
- Photos
- Refreshments (if budget allows)
- Information about next level courses

## TEACHER'S GUIDE

### Preparation Checklist

Before Each Class:
- [ ] Computers powered on and tested
- [ ] Software installed and working
- [ ] Internet connection verified
- [ ] Printed materials ready
- [ ] Homework from previous class reviewed
- [ ] Lesson plan reviewed

### Classroom Management Tips

1. **Pace:** Go slowly, check for understanding frequently
2. **Demonstration:** Show first, then let students practice
3. **Peer Learning:** Pair stronger students with those needing help
4. **Patience:** Remember this may be students' first computer experience
5. **Encouragement:** Celebrate small wins and progress
6. **Repetition:** Review key concepts multiple times
7. **Real-World Examples:** Connect lessons to students' daily lives

### Common Challenges & Solutions

| Challenge | Solution |
|-----------|----------|
| Fear of breaking computer | Emphasize it's okay to make mistakes, demonstrate resilience |
| Different skill levels | Pair students, provide extra help to beginners, advanced tasks for quick learners |
| Language barriers | Use visual aids, demonstrate, use simple language |
| Limited computer access | Maximize lab time, provide practice assignments, partner with schools |
| Power/internet outages | Have offline activities ready, be flexible with schedule |

### Adaptation for Different Learners

**Fast Learners:**
- Provide additional challenges
- Let them help peers
- Introduce advanced features
- Encourage self-exploration

**Slow Learners:**
- Extra practice time
- One-on-one support
- Simplified instructions
- Focus on essential skills first

**Persons with Disabilities:**
- Adaptive equipment if available (larger keyboards, screen readers)
- Seating accommodations
- Extra time for tasks
- Modified assessments if needed
