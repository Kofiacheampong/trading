## Capital Structure Options

### Option 1: 50/50 Split ($150K each)
- Each side gets 50% equity
- Yr 1 return per $150K: **$46,739 (31%)**
- Year 2 projected: **$72K-$77K (48-51%)**

### Option 2: Kofi $100K / Investors $200K
- Kofi: 33.3% equity → Yr 1: **$31,159**
- Investors: 66.6% equity → Yr 1: **$62,319 (31% on $200K)**
- Could layer in a 2x return preference for investors

### Option 3: Preferred Return + Equity Split
- Investors get 8% preferred return ($16K/yr on $200K)
- Remaining profit split 50/50
- Yr 1: Investors get **$16K + $38,739** = $54,739 (27.4%)
- Yr 1: Kofi gets **$38,739 (38.7% on $100K)**
- Math: $93,478 − $16,000 pref = $77,478 remaining ÷ 2 = $38,739 each ✓
