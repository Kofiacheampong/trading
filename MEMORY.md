## Key Lessons Learned
- **VERIFY BEFORE ASSERT (standing rule, added Aug 4 after INTC earnings fiasco; strengthened Aug 12):** Tradeable facts — earnings dates, prices, filings — must be checked against a primary source (company IR, exchange, official filing) before stating them. Never assert an earnings date from web-search snippets without checking the article's date (stale articles from prior cycles look fresh). If unverified, say "unverified." Cite sources for anything trade-affecting. Kofi's trust was damaged by a confident wrong earnings date (claimed Aug 6 earnings; Intel already reported Jul 23; next is late Oct). **Aug 12 addition:** system-status claims count too — I told Kofi the EPL 10 AM ET scan "ran" from memory; the cron table showed Last run: never. Rule: any claim about live systems (crons, sims, scans, backups) gets checked against live state in the SAME turn (openclaw cron list, state files, logs) or I explicitly say "unverified." Never narrate memory as current status.
- **Intraday ES 5-min backtest (8/11/26, 60 days):** opening-range BREAKOUT (ORB) loses hard in the 2026 regime (WR 10-27%, −$1.3K to −$4.1K across variants) — the market chops breakouts. Opening-range FADE (mean reversion, Kofi's style) wins: 45 trades, WR 71%, +$3,429, DD 8.1%. **The SHORT side carries it (85% WR vs 53% longs)** — proof that two-sided tracking beats long-only blinders. Caveats: 60 days = one regime; R:R is razor-thin (1.48 incl. time-exits, gate needs 1.5); close-based fills, no slippage modeled. Paper sim confirms or kills it going forward.
- **ADR/foreign-fundamentals currency trap (fixed 9/28/26, `opportunity.py` v2):** Yahoo `financialData` statement money values arrive in the company's **financial currency** (NVO → DKK, CCJ → CAD), while price/market cap arrive in the **quote** currency (USD). Never blend them. Symptom: NVO printed FCFy 29.1% and EV/EBITDA 1.5 in the 9/26 Quality-on-Discount report (Kofi: "score is meaningless"). Yahoo's own `enterpriseValue` is blended too (USD market cap + local debt/cash: 171.4 + 140.1 − 45.0 = 267.0, matching what it reported), so for mismatched names **rebuild EV and EV/EBITDA from converted parts**. `trailingEps`/`bookValue`/margins/ROE are already quote-currency or currencyless — verified via `priceToBook` (38.80 ÷ 7.60284 = 5.10) — so EY/ROE were never affected. Fix = `fx_rate()` via Yahoo `<FIN><QUOTE>=X` chart meta, convert FCF/OCF/debt/cash/EBITDA, prefer `price.marketCap` (dual-class ADRs: NVO real $171.4B vs $129.7B from ADR-count × price), fail **closed** (metrics None, `fx_failed` → retried next run) if no FX. Also bump `VALUE_CACHE_VERSION` whenever the fundamentals schema changes, or the 7-day cache keeps serving pre-fix garbage. Post-fix NVO: score 88→74, ROIC~76→35, FCFy→3.3%, EV/EBITDA→7.0 — still a legit FLAG, just on real numbers. CCJ was silently affected too. RULE: any new fundamentals source must carry its currency; ratios are currencyless, money is not.
- **options_data.fetch_chain() returns CALLS ONLY** — no puts helper exists (8/11/26: I mislabeled call mids as 'put premiums' on TEAM/NEM/ABNB; the 'absurdly rich $12-17' quotes were calls, and the strike 'inversion' was a give-away). Real 10% OTM puts ≈ $1-2, matching BS math. Use sim.fetch_put_mid / fetch_put_spread_mid (direct Yahoo v7 `options[0].puts` array) for put quotes. VERIFY THE LEG (C/P) BEFORE ASSERTING PREMIUMS.
- **Sim-world weeklies expire THURSDAYS** (TEAM/ABNB/NEM: Aug 13/20/27), Fridays on Cboe — friend's alerts quote phantom Friday expiries (TEAM 'Aug 28' doesn't exist on real chains).
