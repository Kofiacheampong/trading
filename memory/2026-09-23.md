## Infra lesson: PDF generation on the ARM box
`generate-pdf.js` (puppeteer) was broken — Chrome was never installed (or was x64-only). Puppeteer downloaded an **x86-64** Chrome for Testing (no linux-arm64 build exists), which can't run on this ARM host. Fix: installed **WeasyPrint 61.1** via apt (works on arm64) and wrote `projects/md2html.js`, a dependency-free Markdown→styled-HTML converter. New pipeline: `node md2html.js in.md out.html && weasyprint out.html out.pdf`. Also installed `unzip` and `poppler-utils` (pdfinfo/pdftotext/pdftoppm) for verification. Documented in TOOLS.md.
